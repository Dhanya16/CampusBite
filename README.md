# CampusBite - Canteen Management System

## Overview
CampusBite is a **canteen management system** designed to streamline food ordering, menu management, and order processing in college canteens. It provides an **intuitive digital platform** for students, administrators, and counter staff to enhance efficiency and reduce wait times.

## Features
- **User-Friendly Ordering System**: Students can browse 12 food categories, adjust orders, and place them seamlessly.
- **Real-Time Menu Updates**: Admins can dynamically update menu items, availability, and pricing.
- **Order Tracking & Notifications**: Twilio API integration for SMS alerts on order status and successful payments.
- **Efficient Counter Management**: A unified platform for manual order processing and queue optimization.
- **Secure Payments**: Integrated payment gateway for seamless transactions.
- **Review & Feedback System**: Users can share their experiences to improve canteen services.

## Tech Stack
- **Frontend**: HTML5, CSS, JavaScript, Bootstrap 5
- **Backend**: PHP, Laravel 10, jQuery
- **Database**: MySQL, phpMyAdmin
- **Server**: Apache (via XAMPP)
- **Version Control**: GitHub
- **API Integrations**: Twilio for SMS notifications
- **UI/UX Design**: Figma

## How to Use
- **Students**: Browse menu, place orders, and receive SMS alerts for updates.
- **Admins**: Manage menu, update order statuses, and send notifications.
- **Counter Staff**: Process manual orders and manage order queues efficiently.
